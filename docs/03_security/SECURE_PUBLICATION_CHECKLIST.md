# Secure Publication Checklist

Before uploading:
- [ ] No private keys, certificates, PFX/P12 files, or CSRs.
- [ ] No tenant IDs, subscription IDs, object IDs, or personal email addresses.
- [ ] No passwords, client secrets, access tokens, connection strings, or state files.
- [ ] Screenshots are cropped and redacted.
- [ ] Fictional organisation and synthetic users are used.
- [ ] Claims distinguish design, local test, and Azure deployment.
- [ ] Employer names and internal details are absent.
- [ ] Git history is scanned, not only the latest files.
- [ ] Repository secret scanning is enabled.
- [ ] Demo video contains no browser bookmarks, notifications, or account details.
