# Operations Runbook

## Daily
Review high-severity incidents, failed automation, certificate alerts, and Key Vault denial trends.

## Weekly
Review unusual authentication, privileged activity, application errors, and Terraform drift indicators.

## Monthly
Review certificates, access assignments, emergency account monitoring, policy exclusions, dependency updates, and backup evidence.

## Change procedure
1. Record change purpose and risk.
2. Update code or policy specification.
3. Peer review.
4. Test in non-production lab scope.
5. Deploy during the approved window.
6. Validate.
7. Roll back if acceptance criteria fail.
8. Update documentation.

## Access requests
Access requires manager/system-owner justification in the fictional governance model, group-based assignment, expiry where appropriate, and periodic review.
