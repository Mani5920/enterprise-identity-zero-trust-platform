# Compliance Mapping

This is an educational mapping, not a certification or formal audit.

| Platform control | NIST CSF theme | ISO 27001 theme | CIS theme |
|---|---|---|---|
| MFA and Conditional Access | Protect - identity management | Access control | Account management |
| Least-privilege RBAC | Protect | Access rights | Access control management |
| PKI and mTLS | Protect | Cryptography | Data protection |
| Key Vault and managed identity | Protect | Secret/key management | Secure configuration |
| Sentinel logging/detections | Detect | Logging and monitoring | Audit log management |
| Incident playbook | Respond | Incident management | Incident response |
| Terraform and change control | Govern/Protect | Change management | Secure configuration |
| Backup and DR | Recover | ICT readiness | Data recovery |

## Limitations
Control implementation evidence, policy ownership, risk acceptance, audit sampling, and organisational procedures would be required for real compliance assessment.
