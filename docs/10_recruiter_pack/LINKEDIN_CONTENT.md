# LinkedIn Project Entry

## Title
Enterprise Identity & Zero Trust Security Platform

## Description
Designed and developed a portfolio-grade enterprise identity and Zero Trust security platform using Microsoft Entra ID, Azure, PKI, Terraform, Microsoft Sentinel, Python, and PowerShell.

Created a role-based identity model, Conditional Access policy catalogue, private CA hierarchy, certificate lifecycle automation, mutual-TLS API design, Key Vault managed-identity pattern, infrastructure-as-code modules, KQL detection rules, incident response procedures, and end-to-end security test cases.

The project uses a fictional organisation and synthetic data, with publication controls that prevent exposure of credentials, tenant details, certificates, and employer information.

## Skills
Microsoft Azure; Microsoft Entra ID; PKI; OpenSSL; mTLS; OAuth 2.0; OpenID Connect; Azure Key Vault; Managed Identity; Microsoft Sentinel; KQL; Terraform; PowerShell; Python; FastAPI; Docker; GitHub Actions; Zero Trust; IAM; Cloud Security.
