# Recruiter Overview

## Project
Enterprise Identity & Zero Trust Security Platform

## Problem solved
Designed a complete identity-led security architecture for a fictional enterprise, covering workforce access, privileged administration, workload identities, certificate-based trust, secret management, monitoring, testing, and governance.

## What I built
- Entra ID identity and RBAC design
- Conditional Access policy catalogue and safe rollout method
- Private PKI hierarchy with certificate lifecycle scripts
- FastAPI service designed for OAuth token validation and mTLS
- Azure Key Vault and managed identity integration pattern
- Terraform modules for network, vault, monitoring, and application foundations
- Microsoft Sentinel KQL detection rules
- Test strategy, threat model, incident response, DR, risk, and compliance mapping

## Skills demonstrated
Azure, Entra ID, PKI, OpenSSL, OAuth 2.0, OpenID Connect, mTLS, Key Vault, managed identities, Microsoft Sentinel, KQL, Terraform, PowerShell, Python, FastAPI, Docker, GitHub Actions, threat modelling, and security operations.
