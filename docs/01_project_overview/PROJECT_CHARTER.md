# Project Charter

## Objective
Design and demonstrate a secure enterprise identity platform that unifies workforce identity, privileged access, workload identity, PKI, monitoring, and governance.

## Stakeholders
- Executive sponsor: fictional CISO
- Product owner: fictional Head of Security Engineering
- Technical owner: portfolio author
- Consumers: employees, application teams, security operations, auditors

## Deliverables
Architecture, policies, infrastructure code, secure application, PKI scripts, KQL detections, test assets, operational runbooks, compliance mapping, and recruiter overview.

## Constraints
Budget-conscious lab design, no production secrets, no employer data, no unsupported claims, and no destructive automation.

## Definition of done
The repository is internally consistent, safe to publish, documented, testable, and includes clear placeholders where real deployment evidence must be added.
